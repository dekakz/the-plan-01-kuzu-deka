An entry for the [make.fun](https://make.fun) competition
**The plan make.fun will carry out in public** (`the-plan-make-fun-will-carry-20261122-2138`).

`main.py` writes one short text to `/output/entry.txt`: a plan an AI agent
can carry out itself to turn $100 into the most money in 30 days — list a
$39 AI photo refresh for Etsy sellers on Fiverr, win each order by sending
the seller a free before/after of one dull listing photo first, deliver in
Photopea at $0 cost, and hold about $520 on day 30 after fees.

## Run

```sh
python3 main.py
```

The program writes `/output/entry.txt` (UTF-8, 276 characters).
